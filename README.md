 # 🦷 Consultório Odontológico

Projeto desenvolvido para praticar **HTML, CSS e JavaScript**, simulando uma fila de pacientes em um consultório odontológico.

## Funcionalidades

* Adicionar pacientes à fila normal
* Adicionar pacientes em situação de urgência
* Atender pacientes dando prioridade aos casos de urgência
* Exibir o paciente que está sendo atendido
* Exibir a fila de pacientes

## Tecnologias

* HTML
* CSS
* JavaScript

## Objetivo

Projeto desenvolvido como prática de programação, manipulação do DOM e utilização de filas com JavaScript.

## Arquivos

* `index.html` — estrutura da página
* `css.css` — estilos da página
* `consultorio_3.0.js` — lógica do sistema
* Imagens utilizadas no projeto
